```tsx
import { GeneModel } from "react-bio-viz";

<GeneModel gene={gene} width={900} />;
```

`gene` is a GFF-like interval tree: a gene with `children` transcripts, each with exon and CDS
children (`start`, `end`, `strand`, `interval_type`, `attributes`). Click an exon for its details;
pan and zoom along the gene.

<GeneModelExample client:only="react" />

The genomic window is a controllable `viewport`.

## SimpleGeneModel

The same view without the toolbar, and fully controlled — for building your own navigation around it. It
keeps no state: every interaction reports through its `on*Change` callback and shows once you pass
the value back (see [Simple components](../../concepts/controllable-state/#simple-components)).

```tsx
const [viewport, setViewport] = useState<Viewport>();

<SimpleGeneModel gene={gene} viewport={viewport} onViewportChange={setViewport} />
```
